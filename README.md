# tgbot-chronicle-py

Библиотека на Python для Телеграм-ботов, у которых интерфейс — **страница и летопись**, а не
лента сообщений.

- **Страница.** Экран бота — одно сообщение. Переход между экранами переписывает его на
  месте, так что число сообщений не зависит от числа нажатий.
- **Страница всегда последняя.** Запись в историю и переезд страницы вниз — одна операция:
  страница уходит новым сообщением под запись, прежняя удаляется. Если записывать нечего,
  страница переписывается на месте и счётчик непрочитанного не растёт.
- **Летопись или история с делами.** У записи летописи кнопок нет. У записи истории с делами
  одна кнопка раскрывает блок действий. Раскрытым бывает только один блок на чат, он
  сворачивается по таймауту, а страница в это время показывает «Вернуть». На нажатие
  устаревшей кнопки бот отвечает, почему её уже нет, а не молчит.
- **Однородное сворачивается.** Одинаковые события за прошедшие дни сворачиваются в строку
  на день.

Бот описывает свои экраны, перечень событий и действия, а сообщениями управляет библиотека.

Состояние проекта: заводится. Контракт — [`docs/specification/`](docs/specification/index.md).
